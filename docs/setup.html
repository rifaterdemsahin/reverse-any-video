🚀 Reverse Any Video: setup guide

This guide takes you from a clean computer to a running copy of the app. The app analyses a video's script and editing style, then saves each result into a project folder in Azure Blob Storage. Replace every <placeholder> with your own name. Never paste a secret into chat, a file or the repo. 🔒

🎯 What you will have at the end

  • 🌐 The app running on Fly.io at a URL you choose.
  • 🪣 A private storage account in Azure with one container, reverse-any-video.
  • 🔐 Secrets kept in Azure Key Vault. The app reads them when it starts.
  • 📁 Projects you create in the app. Each project is a folder, and each analysis is saved into it.

💻 Choose your computer

Pick your system. Every command in the steps below changes to match.

macOS commands use Terminal (zsh). Windows commands use PowerShell. Linux commands use bash.

🔑 Step 6 · create the access token

⚠️ Without a token, anyone who finds the URL can create projects and start jobs. Those writes go to your storage account. Set one before you share the link.

TOKEN=$(openssl rand -hex 24); echo "$TOKEN" | pbcopy     # the token is now on your clipboard
fly secrets set --stage --app reverse-any-video ACCESS_TOKEN="$TOKEN"
TOKEN=$(openssl rand -hex 24); echo "$TOKEN" | (wl-copy 2>/dev/null || xclip -selection clipboard)
fly secrets set --stage --app reverse-any-video ACCESS_TOKEN="$TOKEN"
$bytes = New-Object byte[] 24
[System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($bytes)
$TOKEN = -join ($bytes | ForEach-Object { $_.ToString("x2") })
Set-Clipboard $TOKEN                       # the token is now on your clipboard
fly secrets set --stage --app reverse-any-video "ACCESS_TOKEN=$TOKEN"
Keep a copy in your password manager. Give the token only to people who should create projects.

📁 Step 8 · create a project and run the first analysis

First load the token from your clipboard into this terminal. Do not type the word TOKEN into the command, paste the real value.

export TOKEN=$(pbpaste)

$TOKEN = Get-Clipboard

Then create the project and start the analysis. On Windows, use curl.exe, because PowerShell's curl is a different command.

🛟 If something goes wrong

You seeLikely cause and fix
{"error":"Missing or wrong X-Access-Token."}The token is missing or wrong. The most common cause is typing placeholder text instead of the token. Run the Step 8 load command again, then retry. Check with echo ${#TOKEN} (macOS and Linux) or $TOKEN.Length (Windows): it should be 48.
Failed to execute 'json' on 'Response': Unexpected end of JSON input in the browserThe server returned nothing, usually because the app crashed on start. Run fly logs --app <your-app>. A missing file in the Docker image is the usual cause: check that the COPY line in the Dockerfile lists every .py file the server imports.
"azure_storage": false in /healthzThe four AZURE_* secrets are missing. Redo Step 5, then Step 7.
HTTP 503 on /api/projectsStorage is not configured. Same fix as above.
HTTP 409 when creating a projectA project with that name already exists. Use a different name.
Job fails with a YouTube sign-in messageYouTube is asking the server to prove it is not a bot. Export cookies.txt from a spare browser account and run fly secrets set YT_COOKIES="$(cat cookies.txt)" --app <your-app>. On Windows, use Get-Content cookies.txt -Raw in place of $(cat cookies.txt).
ModuleNotFoundError: No module named 'httpx2' when running the testsThe newer web test client needs one more package. Run pip install httpx2 in the virtual environment.
ffmpeg: command not foundInstall ffmpeg with the Step install commands for your system, then open a new terminal.
Windows: running scripts is disabled on this systemRun Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, then activate the environment again.
Fly machine stopped and will not startRun fly logs --app <your-app>, fix the cause, then Step 7. Fly stops retrying after a few restarts.

🧹 Clean up

To remove everything: fly apps destroy <your-app>, delete the service principal and its Key Vault secrets, and delete the storage account. Deleting the storage account removes every saved output.
