⚙️ Settings and the access token

Where each setting lives, what it does and what it changes. This page holds no secret values.

🔑 The access token

The token is a password for the analyzer. It is set on the server as the secret ACCESS_TOKEN. Fly.io never shows a secret after it is set, so you cannot copy it back from there.

Where to find it

  1. If you saved it, it is in your password manager, under the name you gave it (for example "reverse-any-video token").
  2. Fly.io lists the secret's name and date, not its value: fly.io/apps/reverse-any-video/secrets.
  3. If you have lost it, set a new one (below). This replaces the old one, and anything using the old token stops working.

Set a new token

TOKEN=$(openssl rand -hex 24) && fly secrets set --app reverse-any-video ACCESS_TOKEN=$TOKEN && echo "$TOKEN" | pbcopy && echo copied

Keep the token private. Anyone with it can start analyses and create projects, which costs money. Do not put it in the page, the repo or chat.

Use it in the analyzer

Open the analyzer, paste the token into the Access token box in the server panel once. The browser keeps it for next time. Another browser or a private window asks again.

🧩 Settings the server reads

Set them with fly secrets set --stage --app reverse-any-video NAME=value, then fly deploy --ha=false. Settings without a secret can be set in fly.toml under [env].
